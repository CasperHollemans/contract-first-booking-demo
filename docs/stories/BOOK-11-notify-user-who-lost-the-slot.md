# BOOK-11 · Notify the user who lost the slot
Status: approved

**As a** user
**I want** to be told right away when the slot I'm booking is no longer available
**So that** I'm notified as soon as possible and can pick another slot

## Acceptance criteria
- When the slot the user is booking is taken by someone else (BOOK-7), the user is notified right away, while still filling in the form.
- The message says the time slot is unfortunately no longer available.
- The user can change their slot.
- The user's name and email are kept when they change their slot.
