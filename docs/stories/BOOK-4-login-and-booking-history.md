# BOOK-4 · Log in and view booking history
Status: draft

**As a** booker
**I want** to log in with my email
**So that** I can view my booking history

## Acceptance criteria
- Login is optional; it is not needed to book.
- By default, login uses a one-time code (OTP) or magic link sent by email.
- After login, the user sees all bookings made with their email address, including bookings made as a guest.

## Open questions
- "Default login is OTP / magic link": are there other login methods besides the default?
- Is it OTP and magic link both, or does the user choose one?
- What does the history show: past bookings, upcoming bookings, or both? Which details?
